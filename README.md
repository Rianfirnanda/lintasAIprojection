# Lintas Benteng Projection

Dashboard pemantauan harga pangan untuk TPID Kabupaten Bengkulu Tengah. Sistem ini mengolah data harga pasar dan konteks pendukung untuk menyajikan tren, proyeksi, peringatan dini, serta bahan tindak lanjut bagi pengendalian inflasi daerah.

Aplikasi menyediakan dashboard web berbasis HTML, JavaScript, dan CSS, pipeline analisis Python, serta integrasi Firebase dan GitHub Actions untuk pemrosesan dan pembaruan data.

Untuk panduan penggunaan dan operasional, lihat [Panduan Operasional](docs/PANDUAN_OPERASIONAL.md).
