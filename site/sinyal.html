Peringatan Harga

Harga yang perlu dicek di lapangan.

    Catat tindak lanjut

    Klik "catat tindak lanjut" pada peringatan, lalu isi di sini.

    Cara memperbarui status
    1. Lewat GitHub Issues (disarankan). Peringatan tinggi otomatis dibuatkan issue berlabel sinyal-harga. Pasang satu label status: status: terverifikasi, status: false-alarm, status: ditindaklanjuti, atau status: selesai. Menutup issue berarti selesai.
    2. Lewat buku tindak lanjut. Buat baris CSV dengan formulir di atas, lalu tambahkan ke berkas di data/tindak_lanjut/.

    Label terverifikasi dan false alarm dipakai untuk menghitung precision dan recall di halaman Akurasi.

    Header berkas: id_sinyal,status,catatan,petugas,tanggal,kode_varian,tanggal_kejadian
