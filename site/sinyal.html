Peringatan Harga

Harga yang perlu dicek di lapangan.

    Catat tindak lanjut

    Klik "catat tindak lanjut" pada peringatan, lalu isi di sini.

    Cara memperbarui status
    1. Lewat GitHub Issues (disarankan). Peringatan tinggi otomatis dibuatkan issue berlabel sinyal-harga. Pasang satu label status: status: terverifikasi, status: false-alarm, status: ditindaklanjuti, atau status: selesai. Kalau issue ditutup, berarti sudah selesai.
    2. Lewat formulir di atas. Bila masuk dengan akun Google, tekan Simpan catatan dan selesai. Tanpa itu, formulir membuat baris CSV untuk ditambahkan ke berkas di data/tindak_lanjut/.

    Label terverifikasi dan false alarm dipakai untuk menilai seberapa tepat peringatan kami di halaman Akurasi.

    Header berkas: id_sinyal,status,catatan,petugas,tanggal,kode_varian,tanggal_kejadian
