Input harga pasar (luring-ke-daring)

Formulir tetap bisa dipakai tanpa sinyal setelah halaman pernah dibuka sekali. Data tersimpan di perangkat sampai diekspor dan dikirim.

Jangan mencatat nama, NIK, nomor HP, atau alamat pedagang. Gunakan kode responden anonim (mis. R1, R2). Berkas yang memuat kolom data pribadi akan ditolak sistem.

Harga per varian

Isi harga eceran per satuan. Kosongkan varian yang tidak tersedia. Peringatan muncul bila harga di luar batas kewajaran.

Cara mengirim ke sistem

  1. Saat ada sinyal, tekan Unduh CSV (atau Bagikan ke operator).
  2. Operator mengunggah berkas ke folder data/masuk/harga/ di repositori: buka halaman unggah → seret berkas → Commit changes.
  3. Pipeline otomatis berjalan: berkas divalidasi, masuk quality gate, dan dashboard diperbarui dalam beberapa menit.
  4. Tekan Hapus yang sudah dikirim setelah operator mengonfirmasi.
