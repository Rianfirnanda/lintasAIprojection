Cara mengirim ke sistem
  1. Tekan Unduh CSV, atau Bagikan ke operator lewat WhatsApp atau email.
  2. Operator mengunggah berkasnya di halaman unggah, lalu menekan Commit changes.
  3. Sistem memeriksa data dan memperbarui dashboard dalam beberapa menit.
  4. Setelah operator memastikan data masuk, tekan Bersihkan yang terkirim.
