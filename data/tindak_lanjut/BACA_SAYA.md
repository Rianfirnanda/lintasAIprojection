# Buku tindak lanjut sinyal

Alternatif GitHub Issues untuk mencatat status sinyal. Buat baris dari halaman **Sinyal & Tindak Lanjut**.
Format: `docs/templat/templat_tindak_lanjut.csv`. Status: `perlu_verifikasi`, `terverifikasi`, `false_alarm`,
`ditindaklanjuti`, `selesai`, atau `anomali_terlewat` (isi `kode_varian` dan `tanggal_kejadian`).
